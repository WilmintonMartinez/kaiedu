# Sistema escolar

Monorepo del sistema escolar.

## Estructura

- `apps/web` — aplicación web (Next.js), desplegada en Vercel
- `apps/mobile` — aplicación móvil (Flutter), pendiente

## Desarrollo web

```bash
cd apps/web
npm run dev
```

Abrir http://localhost:3000

## Vercel

Root Directory del proyecto: `apps/web`
