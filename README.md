# KaiEdu

Plataforma de gestión escolar. Matrícula, asistencia, calificaciones, comunicación con familias y administración institucional.

## Estructura

- `apps/web` — aplicación web (Next.js), desplegada en Vercel
- `apps/mobile` — aplicación móvil (Flutter), pendiente

## Desarrollo web

```bash
cd apps/web
npm run dev
```

Abrir http://localhost:3000

## Vercel

- **Nombre sugerido del proyecto:** `kaiedu`
- **Root Directory:** `apps/web`
